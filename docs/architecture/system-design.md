## 模块职责

### 桌面端 (Wails + Vue 3)

| 模块 | 职责 |
|------|------|
| UI Layer | Vue 3 + Element Plus 组件，路由，状态管理 (Pinia) |
| Canvas Editor | Fabric.js 画布，图像预览、标注、轻量编辑 |
| Go Bridge | Wails 运行时，文件系统访问、本地 SQLite、HTTP 客户端 |
| Local Cache | SQLite 缓存任务/素材元数据，离线可浏览 |

### 云端 API (Go + Gin)

| 模块 | 职责 |
|------|------|
| Auth | JWT 认证、会话管理、设备授权 |
| User | 用户 CRUD、团队管理、角色权限 |
| Asset | 素材上传签名 URL、素材元数据管理 |
| Project | 项目 CRUD、SKU 分组 |
| Generation | 生图任务创建、状态查询、结果获取 |
| Template | 模板管理、平台规则配置 |
| Prompt | Prompt 模板版本管理 |
| Credit | 积分账户、流水、扣费（事务+行锁） |
| Export | 导出任务、ZIP 打包 |
| Storage | 对象存储上传/下载签名 |
| Webhook | 异步回调、外部集成 |

### Worker (Go + Asynq)

| 步骤 | 说明 |
|------|------|
| 预处理 | 背景移除、缩放、格式转换 |
| AI 生图 | 调用 GPT-Image-2 API |
| 后处理 | 平台规则校验、压缩优化 |
| 结果存储 | 上传对象存储、更新任务状态 |

## 安全边界

```text
桌面端                         云端
───────                        ────
❌ 不含 OpenAI 密钥            ✅ 持有 OpenAI 密钥
❌ 不含数据库密码              ✅ 持有数据库密码
❌ 不直接调用 GPT-Image-2      ✅ 调用 GPT-Image-2
✅ 本地文件管理                ✅ 权威业务数据
✅ UI 交互                     ✅ 认证/鉴权/计费
```

## 关键技术决策

1. **Wails** — Go 桌面框架，与云端 Go API 共享语言生态
2. **Gin** — 高性能 HTTP 框架，适合 API 服务
3. **GORM** — Go ORM，支持 MySQL 迁移和事务
4. **Asynq** — 基于 Redis 的任务队列，支持重试/延迟/优先级
5. **MySQL 8.0** — 权威业务数据，支持 CTE/窗口函数/JSON
6. **GPT-Image-2** — 主要生图引擎，云端调用
7. **Element Plus** — Vue 3 企业级组件库
8. **Fabric.js** — Canvas 编辑，支持图层/变换/标注
