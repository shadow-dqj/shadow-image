# 产品需求文档 (PRD)

## 产品定位

面向电商卖家/运营人员的**桌面端 AI 商品图生成工具**。用户在本地桌面应用中手动配置自己的 AI 中转站/API 信息（Base URL、API Key、模型名），上传商品参考图，选择电商平台与图片类型，生成符合平台场景的商品展示图，并支持本地预览、保存、轻量编辑和导出。

MVP 阶段定位为 **Bring Your Own Key 的本地桌面工具**，优先验证电商图片生成业务闭环；不优先建设云端管理后台、用户体系、积分计费和订阅系统。

## 目标用户

- 电商卖家（个人/小团队）
- 电商运营人员
- 跨境电商卖家（Amazon、Shopify、TikTok 等多平台出图）
- 需要快速制作商品主图/场景图/社媒图的设计与营销人员

## 核心业务目标

1. 用商品参考图生成更适合电商平台的商品图。
2. 尽量保持商品外观、颜色、材质、Logo、包装文字和比例。
3. 通过平台预设和提示词优化降低 Prompt 编写门槛。
4. 让用户能使用自己的 AI 中转站或 OpenAI-compatible API。
5. 在桌面端完成上传、提示词优化、生成、审阅、编辑、保存、导出的闭环。

## AI Agent 作图闭环

详细业务流程见：[AI Agent 作图业务流程](agent-image-workflow.md)。

软件应像一个电商作图 Agent 一样工作：

```text
商品导入 → 目标选择 → 提示词优化 → 图片生成 → 结果审阅 → 本地编辑 → 导出归档
```

每一步都围绕电商可用性，而不是单纯调用模型出图。

## P0 — MVP 必备

1. **AI Provider 设置**
   - 手动填写 API Base URL
   - 手动填写 API Key
   - 手动填写/选择模型名
   - 选择接口类型：OpenAI-compatible / 自定义中转站
   - 设置超时时间、默认尺寸、默认质量
   - 测试连接

2. **商品参考图上传**
   - 拖拽上传
   - jpg/png/webp 基础格式校验
   - 本地预览
   - 记录图片尺寸、大小、文件路径

3. **平台/图片类型选择**
   - Amazon 主图：白底、1:1、无文字、无水印
   - Shopify 商品图：方图/场景图
   - TikTok/抖音：竖版广告图
   - 小红书：封面图

4. **Prompt 编辑、模板与优化**
   - 根据平台和图片类型提供默认 Prompt
   - 用户可填写商品信息、卖点、目标风格、禁忌项
   - 一键优化 Prompt：把用户粗略描述改写为稳定的电商生图提示词
   - 自动生成/优化 Negative Prompt / 禁止项
   - 明确提示“保持商品主体不变”

5. **单张 AI 生图**
   - 使用用户配置的 AI API 发起请求
   - 支持带商品参考图的 image-to-image / edit 请求（按中转站能力适配）
   - 显示 loading、错误信息、重试入口
   - 生成结果预览

6. **本地结果管理**
   - 保存生成图片到本地输出目录
   - 保存生成历史：原图、Prompt、模型、尺寸、生成时间、结果路径
   - 支持打开输出文件夹

7. **基础导出**
   - 按平台推荐尺寸保存
   - 支持 jpg/png/webp（按浏览器/本地能力逐步实现）
   - 单张下载/保存

## P1 — 核心增强

8. **批量 SKU 生图**

   - 同一模板批量应用
   - 批量结果预览和导出

   - 添加/编辑广告文字

    - 小红书封面比例建议

11. **本地项目管理**
    - 项目/SKU 分组
    - 素材和生成结果归档
    - 本地搜索和筛选

## 提示词优化功能

提示词优化是 MVP 的核心业务能力之一，目标是把用户的普通描述转成更稳定、更符合电商平台要求的生图 Prompt。

### 输入信息

| 信息 | 示例 |
|------|------|
| 商品名称 | 便携式榨汁杯 |
| 商品类目 | 厨房小家电 |
| 核心卖点 | 便携、无线、易清洗 |
| 目标平台 | Amazon / Shopify / TikTok / 抖音 / 小红书 |
| 图片类型 | 白底主图 / 场景图 / 竖版广告 / 社媒封面 |
| 目标风格 | 简洁、现代、自然光、高级感、年轻化 |
| 禁止项 | 不改 Logo、不改包装文字、不添加人物、不生成文字 |

### 输出结果

- 优化后的英文/中文 Prompt（按模型和中转站习惯可配置）
- Negative Prompt / 禁止项
- 平台规则提示
- 商品保持约束
- 可编辑版本，用户确认后再进入生图

### 优化原则

1. 永远优先保持商品主体一致。
2. 平台规则必须进入 Prompt 或生成参数。
3. 广告文字不直接要求模型生成，优先保留后期编辑空间。
4. 场景、灯光、构图可以变化，但商品形状、颜色、材质、Logo、包装文字不能变化。
5. 输出 Prompt 应结构化，便于用户理解和二次编辑。

## 支持平台规则

| 平台 | 图片类型 | MVP 规格建议 |
|------|---------|-------------|
| Amazon | 主图 | 纯白底、1:1、≥1000px、无文字、无水印 |
| Shopify | 商品图 | 推荐 2048×2048、jpg/png/webp |
| TikTok / 抖音 | 竖版广告 | 9:16、1080×1920、移动优先 |
| 小红书 | 封面 | 3:4 或 4:5、1080×1440 |

## MVP 用户流程

```text
打开桌面工具
→ 首次设置 AI Provider（Base URL / API Key / Model）
→ 上传商品参考图
→ 选择平台与图片类型
→ 填写商品信息/卖点/风格
→ 一键优化 Prompt / Negative Prompt
→ 点击生成
→ 调用用户配置的 AI 中转站接口
→ 预览生成图
→ 本地保存 / 导出
```

## AI Provider 配置需求

| 配置项 | 说明 |
|-------|------|
| Provider Type | OpenAI-compatible 或 Custom Gateway |
| Base URL | 用户填写的 API 服务地址 |
| API Key | 用户填写，本地保存，界面脱敏展示 |
| Model | 用户填写或从本地配置中选择 |
| Request Timeout | 默认 120 秒，可配置 |
| Image Size | 例如 1024x1024、1080x1920、2048x2048 |
| Quality | standard / high，按模型能力映射 |

## 安全与隐私

- API Key 由用户自行填写，只保存在本机。
- MVP 阶段可先本地配置文件保存，后续升级为系统 Keychain/加密保存。
- 不将用户图片、Prompt、API Key 上传到项目自有云端。
- 调用第三方/中转站 API 前，应在 UI 中提示用户数据会发送到其配置的服务商。

## 成本控制

- 用户自带 API Key，费用由用户自己的中转站/模型账户承担。
- UI 需要展示当前模型、尺寸、质量，避免误用高成本配置。
- 提供生成前确认或明显的生成按钮状态。
- 支持失败重试，但避免自动无限重试。

- 管理后台
