# 产品需求文档 (PRD)

## 产品定位

面向电商卖家/运营人员的桌面端 AI 商品图生成工具。用户通过本地桌面应用上传商品图，选择模板/平台规则，调用云端 GPT-Image-2 服务生成符合各电商平台规范的商品展示图，支持批量 SKU 处理和平台规则自动校验。

## 目标用户

- 电商卖家（个人/团队）
- 电商运营人员
- 品牌方设计/营销团队
- 跨境电商卖家（多平台多规格需求）

## 核心功能

### P0 — MVP 必备

1. **用户认证** — 注册/登录/设备授权
2. **商品图上传** — 拖拽上传、格式校验、预览
3. **模板选择** — 按平台/风格/类型选择生图模板
4. **单张生图** — 选择模板 → 创建任务 → 排队 → 生成 → 展示
5. **结果下载** — 单张/批量下载生成图
6. **积分系统** — 积分余额、扣费记录

### P1 — 核心付费

7. **批量 SKU 生图** — 同一 SKU 多角度/多变体批量生成
8. **平台规则校验** — Amazon 白底、Shopify 方形、TikTok 9:16 等自动检测
9. **品牌工具包** — 品牌色、Logo、字体预设
10. **导出打包** — 按平台规则导出 ZIP 包

### P2 — 增强

11. **团队协作** — 多人团队、角色权限
12. **自定义 Prompt** — 高级用户自定义生图 Prompt
13. **历史记录** — 任务历史、素材管理
14. **本地缓存** — SQLite 本地缓存，离线可浏览历史

## 支持平台规则

| 平台 | 图片类型 | 规格要求 |
|------|---------|---------|
| Amazon | 主图 | 纯白底、1:1、≥1000px、无文字、无水印 |
| Shopify | 商品图 | 推荐 2048×2048、≤20MB、jpg/png/webp |
| TikTok | 竖版广告 | 9:16、1080×1920、移动优先 |
| 小红书 | 封面 | 3:4 或 4:5、1080×1440 |

## 用户流程

```text
登录 → 上传商品图 → 创建项目 → 选择模板 → 创建生图任务
→ 预扣积分 → 等待生成 → 预览结果 → 下载/导出
```

## 商业模式

- 免费额度：注册赠送基础积分
- 按量付费：按生图张数/质量扣减积分
- 订阅制：月度/年度套餐含固定积分 + 团队功能
- 批量折扣：批量 SKU 任务积分优惠

## 成本控制

- 低质量预览（低成本）→ 高质量输出（高成本）
- 质量分级：standard / high / ultra
- 异步批量任务，重试次数限制
- 去背景、缩放、压缩用确定性服务（便宜），不调 GPT-Image-2
