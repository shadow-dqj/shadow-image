# code-review (skill)

## 描述

对修改的代码进行质量审查，查找 Bug、简化机会、性能问题。

## 触发条件

- "review / 审查代码"
- "检查这段代码 / check this code"
- 在提交代码前

## 上下文依赖

- `docs/development/coding-standards.md` — 检查是否符合规范
- `CLAUDE.md` — 项目架构约束

## 检查维度

1. **正确性** — 逻辑错误、边界条件、空值处理
2. **安全性** — SQL 注入、XSS、认证/鉴权缺失
3. **性能** — N+1 查询、不必要的循环、缓存缺失
4. **规范** — 命名、分层、错误处理
5. **简化** — 重复代码、过度设计

## Go 特有检查

- 事务使用是否正确
- 积分操作是否有行锁
- 错误是否被忽略
- goroutine 泄漏风险
- 幂等性保证

## Vue 特有检查

- 响应式使用是否正确
- 组件是否过大
- Props/Emits 类型是否完整
